## 4. Consolidated AgentBox capability map

1. **Artifact and lineage foundation:** immutable manifests, content hashes, versions, parent-child DAG, provenance and event records.
2. **Agent factory and registry:** definitions, templates, capability declarations, tool references, policies, packaging and lifecycle.
3. **Runtime and orchestration:** task contracts, bounded execution, scheduling, delegation, resumability, cancellation and recovery.
4. **Tool and connector fabric:** typed input/output schemas, credential references, permission checks, connector lifecycle and audit.
5. **Memory and knowledge:** pluggable memory semantics, source-grounded retrieval, corpus/index snapshots and retention controls.
6. **Cognitive extensions:** goals, perception, planning, reasoning, reflection and world-model interfaces.
7. **Agent Evolution Engine:** constrained mutations, candidate versions, experiments, evaluation, approval, promotion and rollback.
8. **Retrieval Evolution Engine:** retrieval genomes, controlled candidate generation, frozen corpora, held-out evaluation and champion archive.
9. **Model Genetics Engine:** model metadata, compatibility, lineage and experiment adapters; weight-level reproduction remains experimental.
10. **Evaluation and observability:** reproducible traces, tests, benchmarks, cost/latency/quality metrics and regression gates.
11. **Governance and safety:** least privilege, policy enforcement, human approvals, secrets isolation, genuine sandbox boundaries and incident controls.
12. **Distribution and marketplace:** agent packages, publishing, discovery, trust, tenancy and monetization.

## 5. Non-equivalences and engineering safeguards

- Agent-configuration evolution is not neural-network topology evolution.
- Retrieval-genome evolution is not model-weight evolution.
- Cognitive memory semantics are not interchangeable with a vector database.
- Multi-agent collaboration needs governed task contracts and orchestration; unrestricted peer-to-peer messaging is not the default.
- A subprocess or generated-code file writer is not a genuine sandbox. Historical unsafe execution examples must be quarantined.
- Fitness is multi-objective: retain raw metrics, metric direction, normalization, weights, evaluator version and dataset version.
- Use frozen datasets and held-out evaluation to prevent benchmark leakage.
- Never mutate a live production agent in place. Create an immutable candidate, test it, approve it and promote it explicitly.
- Preserve source alternatives and contradictions instead of silently resolving them.
- Track code provenance, maturity and license/copyright constraints before reuse.

11. Add marketplace and vertical-agent capabilities after runtime and governance stabilize.
